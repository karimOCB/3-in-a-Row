# Tic-Tac-Toe: Three in a Row 🕹️

Welcome to **Tic-Tac-Toe: Three in a Row**, a simple yet engaging web-based version of the classic game! Challenge your friends or play against an AI to see who gets three in a row first. 🎉

## 🌐 Live Demo
[Check out the game here!](https://three-in-a-row-backend.onrender.com)

## 📌 Features
- **Classic Gameplay**: Enjoy the timeless fun of Tic-Tac-Toe.
- **Two-Player Mode**: Play with a friend in real time.
- **Responsive Design**: Play seamlessly on desktop, tablet, or mobile devices.
- **Interactive UI**: Clean and intuitive interface for smooth gameplay.
- **Backend Integration**: Handles game logic and match data.

## 🚀 Technologies Used
- **Frontend**: Tailwind, Typescript, Vite
- **Backend**: Node.js, Express, Typescript, MongoDb
- **Hosting**: Render.com
